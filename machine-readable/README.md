# CRAFT machine-readable layer: moved to the one source

The CRAFT family machine-readable layer (per-standard schemas, registers, examples, the
generators, the registry, and the family manifest) is no longer kept in this repo. It lives
as one source in the public **[Polymathie-Studio/tools](https://github.com/Polymathie-Studio/tools)**
repository: sources under `machine-readable/craft/`, generated schemas under `schema/craft/`.

This is a pointer, not a mirror, by design (one source).

- CRAFT family manifest: https://raw.githubusercontent.com/Polymathie-Studio/tools/main/schema/craft/craft-manifest.json
- One source: https://github.com/Polymathie-Studio/tools
